# 清冷科幻 · 充电账单设计规范

**版本**：v1.0
**风格定位**：极地冷灰 · 深空科幻
**适用场景**：深色模式（Dark Mode）电车充电账单工具

***

## 一、设计原则

1. **极暗基底**：以宇宙黑为画布，最大化 OLED 屏幕的沉浸感
2. **低饱和冷色**：所有强调色均控制在 20%-40% 饱和度，拒绝霓虹式高亮
3. **结构优先于装饰**：用黑白灰建立信息层级，彩色仅用于功能标记
4. **无发光依赖**：清冷感来源于色彩本身的灰调质感，不借助 text-shadow 或 glow 效果

***

## 二、颜色令牌（Color Tokens）

### 2.1 背景层级（Background Scale）

表格

| 令牌名             | HEX       | RGB          | 使用场景              |
| :-------------- | :-------- | :----------- | :---------------- |
| `--bg-void`     | `#000000` | `0, 0, 0`    | 最底层画布，页面根背景       |
| `--bg-base`     | `#050508` | `5, 5, 8`    | 页面主背景，比纯黑多一丝蓝灰调   |
| `--bg-surface`  | `#0C0C12` | `12, 12, 18` | 卡片、面板、列表项背景       |
| `--bg-elevated` | `#181820` | `24, 24, 32` | 悬浮卡片、模态框、下拉菜单、选中态 |

**使用规则**：

* 普通卡片使用 `--bg-surface`

* 鼠标悬浮/点击后的卡片提升至 `--bg-elevated`

* 严禁在 `--bg-surface` 上再嵌套一层 `--bg-surface`，必须通过 `--bg-elevated` 区分层级

### 2.2 强调色（Accent Colors）

表格

| 令牌名              | HEX       | RGB            | HSL              | 使用场景                 |
| :--------------- | :-------- | :------------- | :--------------- | :------------------- |
| `--accent-frost` | `#5B8FA8` | `91, 143, 168` | `198°, 31%, 51%` | 核心电能色：电量、费用、充电进度、主图标 |
| `--accent-steel` | `#3D4F6B` | `61, 79, 107`  | `218°, 27%, 33%` | 次要强调：链接、图表第二系列、标签选中态 |
| `--accent-mist`  | `#5A4A6B` | `90, 74, 107`  | `270°, 18%, 35%` | 第三级数据：图表第三系列、装饰性渐变终点 |

**使用规则**：

* 单页面同时出现的强调色不超过 2 种

* `--accent-frost` 为默认强调色，优先用于金额、度数等核心数据

* `--accent-steel` 用于辅助信息，如图例、次要链接

### 2.3 文字色（Text Colors）

表格

| 令牌名                | HEX       | RGB             | 对比度（相对于 `#050508`） | 使用场景              |
| :----------------- | :-------- | :-------------- | :----------------- | :---------------- |
| `--text-primary`   | `#D8DDE4` | `216, 221, 228` | 12.1:1             | 标题、正文、主按钮文字       |
| `--text-secondary` | `#5A6470` | `90, 100, 112`  | 4.2:1              | 描述、标签、时间戳、单位      |
| `--text-muted`     | `#3A4450` | `58, 68, 80`    | 2.1:1              | 禁用状态、占位符、水印、分割线文字 |

**使用规则**：

* 正文必须使用 `--text-primary`，确保 WCAG AAA 级可读性

* `--text-secondary` 仅用于不需要快速扫读的辅助信息

* `--text-muted` 严禁用于功能性文字，仅限装饰性或禁用态

### 2.4 功能色（Semantic Colors）

表格

| 令牌名         | HEX       | RGB            | 使用场景              |
| :---------- | :-------- | :------------- | :---------------- |
| `--success` | `#4A7A6B` | `74, 122, 107` | 充电完成、支付成功、碳减排正向反馈 |
| `--warning` | `#8A6A3A` | `138, 106, 58` | 低电量提醒、价格异常、待处理状态  |
| `--error`   | `#8A3A4A` | `138, 58, 74`  | 充电失败、支付错误、删除操作确认  |

**使用规则**：

* 功能色仅用于状态标记，不作为品牌主色使用

* 成功/警告/错误图标统一使用对应颜色，文字可保持 `--text-primary` 或 `--text-secondary`

### 2.5 边框与分割线（Border Colors）

表格

| 令牌名                | HEX       | RGB          | 使用场景             |
| :----------------- | :-------- | :----------- | :--------------- |
| `--border-default` | `#181820` | `24, 24, 32` | 卡片描边、列表分隔线、输入框边框 |
| `--border-subtle`  | `#0C0C12` | `12, 12, 18` | 极细分割线、表头底边       |

**使用规则**：

* 卡片边框统一使用 `1px solid var(--border-default)`

* 分割线优先使用 `--border-subtle`，降低视觉噪音

### 2.6 主操作色（Action Colors）

表格

| 令牌名                      | HEX       | RGB             | 使用场景             |
| :----------------------- | :-------- | :-------------- | :--------------- |
| `--action-primary`       | `#D8DDE4` | `216, 221, 228` | 主要按钮背景、选中 Tab 背景 |
| `--action-primary-hover` | `#E8ECF0` | `232, 236, 240` | 主按钮 Hover 态      |
| `--action-primary-text`  | `#000000` | `0, 0, 0`       | 主按钮上的文字（黑底白字反转）  |

## 三、字体规范（Typography）

### 3.1 字体栈

plain

```plain
--font-sans: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
--font-mono: 'JetBrains Mono', 'SF Mono', 'Fira Code', monospace;
```

### 3.2 字号与字重

表格

| 层级      | 字号     | 字重  | 行高  | 字体   | 颜色                 | 使用场景       |
| :------ | :----- | :-- | :-- | :--- | :----------------- | :--------- |
| Display | `28px` | 700 | 1.2 | Sans | `--text-primary`   | 页面大标题      |
| H1      | `20px` | 600 | 1.3 | Sans | `--text-primary`   | 卡片标题、模块标题  |
| H2      | `16px` | 600 | 1.4 | Sans | `--text-primary`   | 列表标题、小标题   |
| Body    | `14px` | 400 | 1.6 | Sans | `--text-primary`   | 正文、账单明细    |
| Caption | `12px` | 500 | 1.5 | Sans | `--text-secondary` | 标签、时间戳、单位  |
| Data    | `14px` | 600 | 1.4 | Mono | `--accent-frost`   | 金额、电量、百分比  |
| Micro   | `11px` | 500 | 1.4 | Sans | `--text-muted`     | 水印、角标、禁用提示 |

**特殊规则**：

* 所有金额、电量、百分比等**数字数据**必须使用等宽字体（`--font-mono`），确保位数对齐

* 数据色默认使用 `--accent-frost`，正向变化可用 `--success`

## 四、间距规范（Spacing Scale）

采用 `4px` 基网格系统：

表格

| 令牌名          | 值      | 使用场景                   |
| :----------- | :----- | :--------------------- |
| `--space-1`  | `4px`  | 图标与文字间距、紧凑内联间距         |
| `--space-2`  | `8px`  | 表单元素内部 padding、图表标签间距  |
| `--space-3`  | `12px` | 按钮内部水平 padding、列表项紧凑间距 |
| `--space-4`  | `16px` | 卡片内部 padding、模块之间间距    |
| `--space-5`  | `20px` | 卡片标题区 padding、表单组间距    |
| `--space-6`  | `24px` | 页面边距（移动端）、大模块间距        |
| `--space-8`  | `32px` | 页面边距（桌面端）、区块分隔         |
| `--space-10` | `40px` | 页面顶部安全区、大区块间距          |

## 六、阴影与深度（Elevation）

深色主题下不使用黑色阴影（不可见），改用**带蓝色调的半透明层**：

表格

| 层级                  | 阴影值                                                                   | 使用场景     |
| :------------------ | :-------------------------------------------------------------------- | :------- |
| `--shadow-surface`  | `0 2px 8px rgba(0, 0, 0, 0.5)`                                        | 静态卡片     |
| `--shadow-elevated` | `0 8px 24px rgba(0, 0, 0, 0.6), 0 0 0 1px rgba(255, 255, 255, 0.03)`  | 悬浮卡片、模态框 |
| `--shadow-dialog`   | `0 16px 48px rgba(0, 0, 0, 0.7), 0 0 0 1px rgba(255, 255, 255, 0.04)` | 对话框、底部浮层 |

**注意**：本规范**不推荐使用发光阴影（glow）**。清冷科幻感依赖于色彩的低饱和度本身，任何 text-shadow 或 box-shadow 发光都会破坏克制感。

## 七、组件规范（Components）

### 7.1 主按钮（Primary Button）

css

```css
background: var(--action-primary);
color: var(--action-primary-text);
border-radius: var(--radius-md);
padding: 10px 20px;
font-size: 14px;
font-weight: 600;
border: none;
transition: background 0.2s ease;
```

**状态**：

* **Hover**：`background: var(--action-primary-hover)`

* **Pressed**：`transform: scale(0.98)`

* **Disabled**：`background: var(--bg-surface); color: var(--text-muted); cursor: not-allowed`

### 7.2 次按钮/幽灵按钮（Secondary Button）

css

```css
background: transparent;
color: var(--accent-frost);
border: 1px solid rgba(91, 143, 168, 0.3);
border-radius: var(--radius-md);
padding: 10px 20px;
font-size: 14px;
font-weight: 600;
transition: all 0.2s ease;
```

**状态**：

* **Hover**：`background: rgba(91, 143, 168, 0.08); border-color: rgba(91, 143, 168, 0.5)`

* **Pressed**：`transform: scale(0.98)`

### 7.3 卡片（Card）

css

```css
background: var(--bg-surface);
border: 1px solid var(--border-default);
border-radius: var(--radius-lg);
padding: var(--space-5);
```

**可选装饰**：卡片顶部可添加一条极细的渐变线，增强科幻感：

css

```css
/* 卡片顶部微光分割线 */
.card::before {
  content: '';
  position: absolute;
  top: 0;
  left: 20px;
  right: 20px;
  height: 1px;
  background: linear-gradient(90deg, transparent, rgba(91, 143, 168, 0.12), transparent);
}
```

### 7.4 输入框（Input）

css

```css
background: var(--bg-base);
border: 1px solid var(--border-default);
border-radius: var(--radius-sm);
padding: 10px 14px;
color: var(--text-primary);
font-size: 14px;
```

**状态**：

* **Focus**：`border-color: var(--accent-frost); outline: none;`

* **Disabled**：`background: var(--bg-surface); color: var(--text-muted);`

### 7.5 标签/状态标记（Tag）

css

```css
background: rgba(74, 122, 107, 0.06);  /* 以 success 为例 */
color: var(--success);
border: 1px solid rgba(74, 122, 107, 0.12);
border-radius: var(--radius-sm);
padding: 3px 8px;
font-size: 11px;
font-weight: 500;
```

```css

  height: 6px;

  border-radius: 3px;

}

  height: 100%;
```
