# 冲充电 · 设计规范 v1.1

> 风格：苹果液态玻璃取向，中性光（白/黑透明），不加彩色光晕。可视化版本见 `docs/design-system.html`（可切浅/深）。
> 适用范围：`app/charging-tracker.html` 的全部界面。与 `HANDOFF.md` 的计算口径无关，改 UI 不动数据。

---

## 1. 五条原则

| 原则 | 含义 | 落地 |
|---|---|---|
| 内容先于容器 | 金额、度数、日期先可读 | 卡片保持实色底，只有控制层做玻璃 |
| 光影描述材质 | 光只解释「这是浮起来的玻璃」 | 顶栏 / 底栏 / 弹层给高光边与投影；卡片只给 1px 级投影 |
| 一步一动作 | 默认路径只留一个决定 | 记一笔只要度数 + 金额；SOC/里程折叠 |
| 数字要对齐 | tabular-nums、右对齐、同量纲同字号 | 系统字体 + 等宽数字 |
| 状态只用色相 | 颜色只表达正常/提醒/危险 | 无彩色强调；主按钮墨色反底 |

明确不做：彩色渐变、彩色光晕、发光脉冲、文字阴影、卡片 `backdrop-filter`、玻璃卡套玻璃卡、骨架屏高光扫过、鼠标跟随高光。

---

## 3. 字体

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| Large Title | 34 / 38 | 600 | 总费用 |
| Title 2 | 22 / 26 | 600 | 区块标题 |
| Title 3 | 20 / 24 | 600 | 行内大数 |
| Body | 17 / 22 | 400 | 正文、记录度数 |
| Subhead | 15 / 22 | 400 | 常规文本 |
| Footnote | 13 / 18 | 400 | 说明、指标标签 |
| Caption 1 | 12 / 16 | 400 | 日期、单位 |
| Caption 2 | 11 / 16 | 400 | 最小注释 |

- 字距：<20px 为 0；20–27 为 `-0.01em`；≥28 为 `-0.02em`。
- 字重只用 400 / 500 / 600。
- 全局 `font-variant-numeric: tabular-nums`；金额与度数不再用等宽字体。
- 页面边距 20px，卡片内边距 16px，行高 52–60px，正文最大宽度 600px。

## 4. 形状与层级

- 圆角：控件 10 / 卡片与列表组 14 / 弹层上圆角 22 / 胶囊 999。
- 内容层级：`--c-bg` → `--c-surface` → `--c-surface-2`，用 0.5px 线与极浅渐变分层。
- 光效层级：内容卡片只有 1px 级投影；玻璃层才有大投影与顶部高光边。
- 玻璃镜面边：`.hero / .tabbar / .sheet` 用 `--rim-gradient` + `mask` 合成 1px 边，亮部在左上、暗部在右下。
- 点击目标 ≥44×44；视觉可 32，用内边距或伪元素补。

---

## 5. 材质边界

| 用玻璃（backdrop + 高光边 + 投影） | 不用玻璃 |
|---|---|
| 顶栏、浮动底栏、底部弹层、确认框、表单操作条、Toast | 卡片、列表组、指标块、表单行、图表区 |

- 内容卡片：`--surface-tint` + `--shadow-card` + `--glass-card-rim` + 发丝线，不透明。
- Hero 是唯一允许稍强光效的内容块：`--hero-tint` + 顶部斜向高光 + 1px 级投影。
- 弹层内部不套玻璃；材质只编码「浮在内容之上」。
- 弹层打开时 `body.sheet-open` 会临时关掉顶栏 / 底栏 / 操作条的 blur，控制同屏模糊层数 ≤2。
- 不支持 `backdrop-filter` 时回退实色；`prefers-reduced-transparency` 同样回退实色并去掉渐变。

## 6. 页面

### 统计页（默认首屏）

- 底栏顺序「统计 / + / 记录」，启动即落在统计。
- 顶栏：车辆名 + ⌄ 打开车辆切换弹层；右侧设置。
- 年份收进工具栏菜单（全部 / 各年份），右侧记录数。
- Hero：34px 总额 + 同比胶囊（累计口径不显示环比）+ 13px 三个次级数。
- 趋势：四档分段（费用/度数/电价/电耗）+ 140px 折线；无样本月份断点，不画 0；入场描线 640ms。
- 快慢充：88px 环 + 图例 + 价差提示。
- 电耗 / 电池：同一套三格指标，点击开明细。
- 建议：卡内前 3 条，超出「查看全部」。

### 记录页

- 顶栏：车辆名 + ⌄；右侧筛选（带数量点）+ 设置。
- 本月条：56px 一行，金额 20px，次数/均价 13px，整行进统计。
- 列表：每年一个 inset group；月份为组内分段头（费用 · 次数）。
- 行：34px 图标块 + 度数 17/600 + 标签 + 日期/SOC 12 + 金额 17/600。
- 切回记录页保留上次滚动位置；首次进入列表错峰 22ms/行。
- 筛选：底部弹层草稿态，重置 / 应用。
- 空态：96×72 线稿 + 一句可执行文案 + 主按钮。

### 设置页

- 从右侧推入（16px + 淡入），退出反向；不整屏滑出。
- 外观：跟随系统 / 浅色 / 深色 三档分段，切换时用 View Transition 交叉淡入（不支持则即时）。
- 车辆 / 数据 / 高级三段，行高 52px。
- 进入设置压历史栈，系统返回先回上一页。

### 记一笔

- 主区：类型分段 + 度数 / 金额 / 日期。
- 金额下方实时显示 `≈ ¥1.20/度`。
- 上次：一行摘要 + 「套用」只套单价。
- 补充信息折叠；校验为字段红描边 + 12px 文案。
- 底部操作条材质化；保存后停留本页可连续补录。

### 弹层

- 抓手 40×4 + 标题/副标题 + 关闭；最大 82dvh；打开压历史栈。
- 入场 340ms 弹簧，退场 200ms 加速下滑；退场期间保留 `display`，用 `is-closing` 承接。
- 承载：月明细、快慢充、电池、建议全量、充电详情、车辆切换、筛选、年份、车辆详情。

## 7. 动效

| 场景 | 做法 | 时长 / 曲线 |
|---|---|---|
| 按压 | `scale(.97)` | 110ms |
| 页签切换 | 新面板 `translateY(6px)` + 淡入 | 220ms `--ease-out` |
| 底栏指示器 | 位移 + 宽度变化 | 320ms `--ease-spring` |
| 弹层入场 | `translateY(100%) → 0`，遮罩淡入 | 340ms 弹簧 / 240ms |
| 弹层退场 | 下滑 + 遮罩淡出 | 200ms `--ease-in` / 180ms |
| 表单 / 设置页 | `translateX(16px)` + 淡入 | 320ms `--ease-out` |
| 页面退场 | `translateX(12px)` + 淡出 | 180ms `--ease-in` |
| 确认框 | `scale(.94) → 1` / 反向 | 220ms / 160ms |
| 记录列表 | 行淡入上移，`--i × 22ms`，上限 14 | 320ms |
| 折线图 | `pathLength="1"` 描线，面积随后淡入 | 640ms / 480ms |
| Hero 数字 | 0 → 目标值 | 320ms |
| 主题切换 | View Transition 交叉淡入 | 280ms |
| Hero 视差 | 仅高光层 `translateY(scrollY × .12)`，上限 10px | 滚动 rAF |

规则：
- 退场动画不推迟状态变更：`_stack.pop()`、`_sheetOpen = false`、`aria-hidden` 先完成，只把 `.show` 换成 `.is-closing`。
- 静默关闭（弹层 → 表单页）跳过动画，避免层级压住与历史条目复用冲突。
- 快速连点：打开新层时取消同元素的 `is-closing` 与定时器。
- `prefers-reduced-motion: reduce` 时直接隐藏，不等待过渡。

---

## 8. 无障碍

- 正文 4.5:1，大字/图形 3:1。
- 每个 icon-only 按钮有 `aria-label`；弹层 `role="dialog" aria-modal="true"`。
- 焦点环 2px 主文色 + 2px 偏移。
- `prefers-reduced-motion` 取消位移与描线；`prefers-reduced-transparency` 材质变实色。
- 不支持 `backdrop-filter` 时控制层回退 `--c-surface`，不依赖模糊保证可读性。

---

## 9. 图标与占位

- 图标：24×24、1.5px、圆头、1px 栅格对齐；页签给线性 + 填充两版。
- 全部 `currentColor`，尺寸由容器控制；入口统一 `Icons.xxx`。
- 空态插画：96×72、1.25px 线稿、`currentColor` + 55% 不透明度；入口 `Illustrations.emptyXxx`。
- 无数据图表：虚线框 + 说明，不画 0 折线。
- 不引入位图；需要时按 2x 放进 `app/assets/`。
