冲充电 · 新设计方案

Apple Human Interface 风格 · 扁平化 · 简洁高效

iOS 18 设计语言 Light / Dark 双模式 SF Pro 字体系统 8pt 间距网格 系统语义色

设计原则

从「清冷科幻 · 深空色调」转向「清晰自然 · 苹果质感」，核心目标：简洁、高效、易用。

扁平克制

去除磨砂玻璃、渐变光效和发光阴影。用背景色层级和间距区分内容，而非装饰性效果。

信息优先

核心数据（费用、电量、电耗）使用 SF Mono 等宽字体，大字号呈现，辅助信息退让到 secondary/tertiary 层级。

操作高效

关键操作（记录充电、查看分析）在一步内可达。表单分组使用 iOS Inset Grouped 风格，减少认知负荷。

系统一致

统一使用 Apple 系统语义色：蓝色表示费用/默认操作，绿色表示成功/健康，橙色表示警告，红色表示错误。

色彩系统

采用 Apple System Colors，支持 Light / Dark 双模式自动切换。从深空黑转向清晰的白/浅灰背景。

设计风格对比

从「清冷科幻 · 深空」到「苹果质感 · 扁平自然」的核心变化。

旧方案
清冷科幻 · 深空色调
  • 纯黑背景 #000000，OLED 沉浸感
  • 低饱和冷色调，强调色 20-40%
  • 磨砂玻璃质感 backdrop-filter
  • 无发光依赖，清冷灰调质感
  • Inter + JetBrains Mono 字体
  • 4px 基网格间距系统
  • 14px 圆角，科幻风格
  • 自定义 SVG 图标库
新方案
苹果质感 · 扁平自然
  • 白/浅灰背景 #FFF / #F2F2F7，清晰明亮
  • Apple 系统语义色，语义明确
  • 扁平卡片 + 微妙阴影，去除磨砂
  • 信息层级靠间距和色彩，非装饰效果
  • SF Pro / -apple-system 字体栈
  • 8pt 基网格间距系统
  • 8-20px 连续圆角，Apple 风格
  • SF Symbols 风格图标 + 语义色背景
  • 支持 Light/Dark 模式自动切换
  • iOS Inset Grouped 列表风格

迁移要点

保持应用功能逻辑不变，仅替换视觉层设计系统。

CSS 变量替换

将 :root 中的颜色令牌从深空黑替换为 Apple 系统色，一键切换整体配色。新增 prefers-color-scheme 媒体查询实现 Dark Mode。

组件样式更新

卡片去除 backdrop-filter，改为微妙阴影。圆角从 14px 调整为 8-20px 分级。按钮改为 iOS 标准样式。列表项采用 Inset Grouped 风格。

布局间距调整

间距从 4px 基网格升级为 8pt 基网格。页面边距调整为 16-24px。卡片间距增大，提升呼吸感。

字体栈更新

Inter 替换为 -apple-system / SF Pro Display。JetBrains Mono 替换为 SF Mono。字号层级对齐 iOS HIG 规范。
