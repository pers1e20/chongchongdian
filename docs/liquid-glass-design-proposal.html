冲充电 · Liquid Glass 设计方案

macOS 26 / iOS 26 液态玻璃设计语言 · 毛玻璃 · 深度 · 动态材质

Liquid Glass 材质 backdrop-filter 毛玻璃 浮动控件层 镜面高光 胶囊形态 Light / Dark 自适应

设计原则

从「扁平卡片」转向「液态玻璃材质」。控件层浮动于内容层之上，半透明玻璃折射背景内容，产生深度与动态感。

玻璃材质优先

所有控件和导航层使用 Liquid Glass 材质：半透明 + backdrop-filter 模糊 + 饱和度补偿 + 镜面边框高光，内容从下方透出。

两层架构

Liquid Glass 控件层浮动于内容层之上。导航栏、标签栏、工具栏为玻璃浮层；数据内容直接渲染在背景上，不被玻璃包裹。

动态折射

玻璃材质动态响应背景内容变化，颜色随背后内容自适应。滚动时内容从玻璃下方透出，产生空间深度。

胶囊形态

交互控件优先使用胶囊形（Capsule），半径等于高度的一半。嵌套元素采用同心圆角，自动从父容器减去内边距。

Liquid Glass 材质系统

两种材质变体：Regular（通用控件层）和 Clear（媒体层上方高透明）。通过 backdrop-filter 实现毛玻璃效果。

Regular Glass · 通用控件层
background: rgba(255,255,255,0.55)
backdrop-filter: blur(24px) saturate(180%)
border: 0.5px solid rgba(255,255,255,0.35)
box-shadow: specular-top + edge
Clear Glass · 媒体层上方
background: rgba(255,255,255,0.15)
backdrop-filter: blur(16px) saturate(150%)
border: 0.5px solid rgba(255,255,255,0.12)
box-shadow: specular-top
Elevated Glass · 悬浮层
background: rgba(255,255,255,0.55)
backdrop-filter: blur(24px) saturate(180%)
box-shadow: shadow-lg + specular-strong
用于模态框、底部浮层
Float Glass · 浮动导航
background: rgba(255,255,255,0.55)
backdrop-filter: blur(30px) saturate(200%)
box-shadow: shadow-float + specular
用于 Tab Bar / Nav Bar 浮层

设计风格对比

从「iOS 18 扁平」到「macOS 26 Liquid Glass 液态玻璃」的核心变化。

旧方案 · iOS 18 扁平
扁平卡片 · 不透明白底
  • 纯白/浅灰不透明背景 #FFF / #F2F2F7
  • 实心卡片，无背景内容透出
  • 固定边框分割线，1px solid
  • 标准圆角矩形按钮
  • Tab Bar 固定底部实心栏
  • 阴影仅用于卡片深度
  • 色彩与背景无动态关系
新方案 · macOS 26 Liquid Glass
液态玻璃 · 半透明浮层
  • 壁纸级渐变背景，玻璃折射内容
  • 半透明玻璃面板，backdrop-filter 模糊
  • 0.5px 玻璃边框 + 镜面高光
  • 胶囊形按钮（Capsule）
  • 浮动玻璃 Tab Bar，28px 大圆角浮层
  • saturate(180%) 补偿模糊饱和度损失
  • 玻璃颜色随背景动态自适应
  • Regular / Clear 双材质变体
  • 两层架构：控件层浮动于内容层之上
  • Light / Dark 模式自动切换

CSS 实现要点

Liquid Glass 材质的核心 CSS 属性和实现参数。

核心材质 CSS
.glass { background: rgba(255,255,255,0.55); backdrop-filter: blur(24px) saturate(180%); -webkit-backdrop-filter: blur(24px) saturate(180%); border: 0.5px solid rgba(255,255,255,0.35); box-shadow: 0 2px 8px rgba(0,0,0,0.08), inset 0 1px 1px rgba(255,255,255,0.6); }
浮动 Tab Bar
.tabbar-float { margin: 0 12px 12px; border-radius: 28px; background: rgba(255,255,255, 0.12); backdrop-filter: blur(30px) saturate(200%); border: 0.5px solid rgba(255,255,255,0.15); box-shadow: 0 8px 32px rgba(0,0,0,0.12); }
Dark Mode 适配
@media (prefers-color-scheme: dark) { :root { --glass-regular-bg: rgba(28,28,30,0.62); --glass-regular-border: rgba(255,255,255,0.10); --label-primary: rgba(255,255,255,0.96); } }
镜面高光
/* 玻璃顶部高光 */ box-shadow: inset 0 1px 1px rgba(255,255,255,0.6), inset 0 0 0 0.5px rgba(255,255,255,0.3); /* 玻璃边缘高光 */ border: 0.5px solid rgba(255,255,255,0.35);
胶囊形态
/* Capsule: 半径=高度/2 */ .btn { border-radius: 9999px; padding: 12px 26px; } /* Float Tab Bar */ .tabbar { border-radius: 28px; margin: 0 12px 12px; }

迁移要点

从当前「清冷科幻」设计系统迁移到 Liquid Glass 液态玻璃风格。

背景层改造

从纯黑 #050508 改为壁纸级渐变背景。Liquid Glass 需要背后有内容才能产生折射效果。深色模式使用深蓝/深紫渐变。

材质替换

所有卡片从不透明 --bg-surface 替换为半透明玻璃材质。backdrop-filter: blur(24px) saturate(180%) + 0.5px 玻璃边框 + inset 镜面高光。

浮动导航

导航栏和 Tab Bar 从固定实心栏改为浮动玻璃浮层，28px 大圆角，margin 隔离屏幕边缘，blur(30px) saturate(200%)。

形状与圆角

按钮改为胶囊形（9999px）。卡片圆角从 14px 增大到 16-28px。浮层使用 28px 大圆角。嵌套元素采用同心圆角。
