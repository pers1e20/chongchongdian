01设计原则

五条，按优先级排序。冲突时上面压下面。

原则含义落到这个应用
内容先于容器先保证金额、度数、日期可读，再用材质包装。卡片永远是实色，只有浮动控制层用玻璃。
光影描述材质光只解释「这是浮起来的玻璃」，不用于装饰内容。控制层给高光边与投影；卡片只给 1px 级投影。
一步一动作默认路径只留一个决定，高级项收一层。记一笔只要度数 + 金额；SOC 与里程折叠。
数字要对齐系统字体 + tabular-nums、右对齐、同一量纲同一字号。金额与度数不跳位，取消全量等宽。
状态只用色相区分颜色只表达正常 / 提醒 / 危险，不做装饰。无彩色强调；主按钮用墨色反底。
明确不做：彩色渐变、彩色光晕、发光脉冲、文字阴影、卡片 backdrop-filter、玻璃卡套玻璃卡、骨架屏高光、鼠标跟随高光、emoji 当图标。

05材质与层级

玻璃只给「浮在内容之上」的控制层：顶栏、浮动底栏、底部弹层、确认框、表单操作条、Toast。四件套是饱和模糊、顶部高光、柔和投影、镜面边；内容层只给极浅渐变与 1px 级投影。

规则做法
材质厚度顶栏、底栏、弹层统一 30px blur；浅色玻璃底 90–95%，深色 88–92%。越靠近前景越厚。
光效范围控制层：高光边 + 外投影 + 镜面边；内容卡片：只加 1px 级投影与极浅表面渐变；Hero 例外，允许更明显的顶部高光。
不叠层弹层里不再套玻璃卡；弹层内容用实色。卡片一律不加 backdrop-filter。
描边玻璃层用 0.5px 外描边 + 1px 高光/暗边；内容层用 60,60,67 的 16% 发丝线。
降级prefers-reduced-transparency → 实色；prefers-reduced-motion → 取消位移；不支持 backdrop-filter → 实色回退。
浮层层级页面 100 → 表单页 110 → 弹层 200 → 确认框 250 → Toast 300。表单页必须高于设置页，否则会被整层盖住。

07页面

两个页签 + 中央记一笔 + 两张表单 + 一类通用弹层。默认落在统计；记录页退为第二页签。线框只标结构，颜色与字号按前面的规格。

统计页

  • 年份：工具栏左侧一个菜单按钮，右侧显示该范围记录数。
  • Hero：34px 总额 + 环比/同比胶囊 + 13px 三个次级数。
  • 趋势：四档分段切换，140px 折线；无样本月份断点，不画 0。
  • 快慢充：88px 环 + 图例 + 价差提示（卡底发丝线，无彩色底）。
  • 电耗 / 电池：同一套三格指标组件，点击开明细。
  • 建议：卡内前 3 条，超出显示「查看全部」。

记录页

  • 顶栏：标题 = 车辆名 + ⌄，点开车辆切换弹层；右侧筛选（带已选数量）与设置。
  • 本月条：56px 一行，金额 20px，次数与均价 13px；整行可点进统计。
  • 列表：每年一个 inset group；月份作为组内分段头，只留「费用 · 次数」。
  • 行：34px 图标块 + 度数（17/600）+ 标签 + 日期/SOC（12）+ 金额（17/600）。
  • 筛选：底部弹层草稿态，重置/应用两个动作，应用后才重绘列表。
  • 空态：线稿 + 一句可执行文案 + 主按钮。

设置页

  • 外观：三档分段控件，点选即生效，无需保存。
  • 车辆：每行显示名称、容量、当前标记；点击进车辆详情弹层。
  • 数据：导出 / 导入 / 恢复快照，导入前二次确认。
  • 高级：技术说明折叠、清空数据（危险色，仅文字）。
  • 返回：进入设置压历史栈，系统返回先回上一页。

记一笔

  • 主区：类型分段 + 度数 / 金额 / 日期三行。
  • 实时反馈：金额下方显示 ≈ ¥1.20/度，省掉心算。
  • 上次：一行摘要 + 右侧「套用」，只套单价。
  • 补充信息：折叠；填里程才能算电耗，填 SOC 才能算容量。
  • 校验：字段红描边 + 12px 文案，不抖动整页。
  • 保存：底部操作条（玻璃），保存后停留本页可连续补录。

弹层

  • 结构：抓手（40×4）+ 标题 / 副标题 + 关闭；正文实色卡。
  • 高度：内容自适应，最大 82dvh；超过内部滚动。
  • 承载：月明细 / 快慢充 / 电池 / 建议全量 / 充电详情 / 车辆切换 / 筛选 / 年份 / 车辆详情。
  • 返回：打开即压历史栈，系统返回先关弹层。
  • 关闭：点遮罩、点关闭、下拉抓手、Esc 四种都可。

08动效

只用 transform 与 opacity。进快出慢，弹层用弹簧；关闭动画不推迟状态变更。所有位移都可被 prefers-reduced-motion 取消。

页签切换新面板 translateY(6px) + 淡入220ms / ease-out
底栏指示器位移 + 宽度变化320ms / spring
弹层入场translateY(100%) → 0，遮罩淡入340ms / 240ms
弹层退场下滑 + 遮罩淡出200ms / 180ms
表单 / 设置页translateX(16px) + 淡入320ms / ease-out

确认框scale(.94) → 1 / 反向220ms / 160ms
记录列表行淡入上移，--i × 22ms，上限 14320ms
折线图pathLength="1" 描线，面积随后淡入640ms / 480ms
Hero 数字0 → 目标值320ms

Hero 视差仅高光层位移，上限 10px滚动 rAF
曲线：ease-out 用于入场，ease-in 用于退场，ease-spring 只给弹层与底栏指示器。不做「发光脉冲」「骨架屏高光扫过」「鼠标跟随高光」。

09无障碍

项标准本应用做法
对比度正文 4.5:1，大字 3:1三级文按 4.5:1 反推取值，已列表核算
点击目标≥44×44图标按钮 44×44；视觉 32，用内边距补
焦点可见2px 描边 + 2px 偏移主文色描边，不用蓝色系统环
不靠颜色传信息颜色 + 文案/图标快慢充有文字标签；状态有「已剔除」等说明
减少动态prefers-reduced-motion位移归零，只保留淡入
减少透明prefers-reduced-transparency材质变实色，模糊关闭
屏幕阅读语义标签icon-only 按钮有 aria-label；弹层 role=dialog + aria-modal
