小程序 / App 迁移说明

本应用采用数据层与渲染层分离的架构，便于迁移：

1. 微信小程序：将 charging-tracker.js 中的 localStorage 替换为 wx.setStorageSync / wx.getStorageSync，渲染层将 DOM 操作替换为 WXML + setData。

2. 原生 App：将 Store 的存储替换为 SQLite 或 AsyncStorage（React Native）。

3. 云同步：数据结构已含 id / createdAt 字段，可直接作为数据库 Schema。

4. 车型库扩展：当前为手动填写，后续可新增 vehicles_db 表预置主流车型参数。
