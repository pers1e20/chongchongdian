# 冲充电 · 交接包

新能源电车充电记账与电池健康分析工具（纯前端 PWA）。本包用于迁移到其他 agent / 开发环境继续迭代。

## 从这个文件开始

- **先读 [HANDOFF.md](./HANDOFF.md)**：产品需求、功能地图、数据模型、计算口径、代码地图、已知坑与重构建议都在这一份里，避免先啃 3000 行源码。
- `app/`：可直接运行的完整源码（无构建步骤）。
- `docs/screenshots/`：当前 6 个核心页面的实机截图，仅作 UI 现状参考。

## 本地运行

```bash
cd app
python3 -m http.server 8000
# 打开 http://localhost:8000
```

首次启动会自动写入一辆示例车（智己 L6，75 kWh）和 28 条充电记录。清空数据后刷新即可重新生成：

```js
localStorage.removeItem('ev_charging_data_v1');
```

- 原项目中的 `docs/设计规范.md`、`docs/部署规则.md`、`tests/`、历史原型和截图未打包——它们与后续要重做的设计/部署强相关且互相重复，按需从原仓库取用。
