# 冲充电

个人新能源电车充电记账与电池健康分析工具。基于纯静态网页实现，记录每次充电的度数、电费、前后电量与里程，并据此推导能耗、充电成本、快慢充习惯与电池容量老化趋势。整个应用是一个 PWA，可离线使用并添加到手机主屏，以接近原生应用的体验运行。

## 核心能力

- **充电记账**：记录充电日期、类型（慢充/快充）、度数、单价与总费用，费用与度数双向自动互算；可选记录里程读数与充电前后电量。
- **月度与年度统计**：趋势图支持左右滑动查看全部历史，并支持按年份、月份筛选查看；呈现总费用、总度数、平均电耗、快慢充占比等指标。
- **电池健康分析**：根据「单次充入度数 ÷ SOC 变化比例」估算实际容量，结合充电习惯给出综合健康度（容量保持率 × 60% + 充电习惯评分 × 40%）。
- **充电建议**：基于历史快慢充、深放、过充比例给出针对性的充电方式建议。
- **数据管理**：支持 JSON 导入导出备份；`localStorage` 持久化，单设备离线可用。

## 技术架构

数据层、算法层与渲染层分离，核心算法为纯 JS 函数，便于日后迁移到小程序或原生 App：

- **数据层** `Store`：封装 `localStorage` 读写，承载车型与充电记录实体。
- **算法层** `BatteryHealth`、`Recommender`：容量估算、健康指数、习惯评分、充电建议，均为纯函数。
- **渲染层** `App`、`Stats`、`Charts`：HTML + Canvas 图表，一组与 DOM 分离的渲染函数。
- **图表** `Charts`：Canvas 绘制，支持首页费用、统计页费用、统计页电耗、电池容量四条趋势的可视化与触摸交互。

## 数据模型与算法要点

- **实体**：车型（品牌、型号、电池容量、是否支持快充）与充电记录（日期、类型、度数、单价、总费用、SOC 前后值、里程）。
- **容量估算**：`容量 = 充入度数 / ((SOC后 - SOC前) / 100)`，仅取 SOC 跨度 ≥ 30% 的记录，当前值取最近 5 次样本中位数，趋势按月取中位数。
- **健康指数**：`容量保持率 × 60% + 习惯评分 × 40%`；习惯评分由快充占比、深放（起点 < 20%）、过充（终点 > 90%）按权重扣分得到。
- **本地存储**：数据仅保存在当前设备的浏览器 `localStorage`，同一账号跨设备不自动同步，换机请先导出备份。

## 本地运行

应用为纯静态文件，无需构建。在 `app/` 目录启动任意静态服务即可：

```
cd app && python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000` 即可访问。

## 部署（Cloudflare Pages）

1. 登录 [Cloudflare Pages 控制台]，选择 **Create project → Upload assets**。
2. 将 `app/` 目录内的 7 个文件整体上传，得到 `https://<项目名>.pages.dev` 的 HTTPS 地址。
3. 手机浏览器打开该地址，添加至主屏幕即可作为应用使用。

**更新流程**：修改代码后，将更新后的文件重新上传覆盖即可。若修改涉及缓存相关文件，需同步递增 `sw.js` 中的 `CACHE_NAME` 版本号，确保手机端能加载新版本。

## 数据备份

在应用的「我的 → 导出备份」可下载 JSON，通过「导入备份」恢复。建议换机或清空浏览器数据前先行导出。
